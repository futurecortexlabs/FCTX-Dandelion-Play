## これは何か

草むしりをしたことがあれば覚えがあるはずです。葉っぱを持って引っぱるとブチッとちぎれて、根が残り、また生えてくる。うまく抜けたときだけ、根っこが一本まるごとスルッと出てくる。

その一瞬だけを遊ぶおもちゃです。地面は断面で描いてあるので、土の中の主根と側根（ひげ根）を見ながら抜けます。画面の文字は日本語です。

| 操作 | 起きること |
|:--|:--|
| **花や葉っぱをつかむ** | 指のほうへしなり、ちぎれ度のゲージが上がる。引っぱりすぎるとブチッとちぎれて、切り口から白い汁（乳液）が出る |
| **じょうろで水をやる** | 水がしみこむと土の色が濃くなり、根をつかむ力が弱まる。株の近くに落ちた水だけが効く |
| **くさぬきで土をほぐす** | 根元のまわりをこすると土が盛り上がって、フカフカになる |
| **根元をつかんで揺らす** | 左右に揺らすと土がほぐれ、側根がプチプチと一本ずつ外れる |
| **真上に引っぱる** | 根のどこも限界を超えなければ、先端まで「スポッ！」と抜ける。斜めに引いたり急に引いたりすると途中で切れる |
| **抜いたあと** | 抜けた長さとランクが出る。根が切れたときは、土に残った根から新しい芽と葉と花が伸びて、また生えてくる |

新しい株は5種類からランダムに選ばれます。

| 品種 | 根の深さ | 土のつかみ | |
|:--|:--|:--|:--|
| セイヨウタンポポ | 72 % | 0.95 | 花が2本。揺らせば抜ける |
| カントウタンポポ | 66 % | 0.82 | 花が1本。いちばんやさしい |
| シロバナタンポポ | 76 % | 1.10 | 白い花びら。根が少し深く、水やりが効く |
| わたげタンポポ | 80 % | 1.15 | 綿毛。揺らすと種が飛び、強く引くと茎がちぎれる |
| ヌシの大タンポポ | 88 % | 1.45 | 茎が3本で、根がいちばん太い。じょうろとくさぬきが必須 |

根の深さは、地下の領域のうち主根が届く割合。土のつかみは、土が根を引き留める強さです。

## 遊び方

- **オンライン:** [futurecortexlabs.github.io/FCTX-Dandelion-Play](https://futurecortexlabs.github.io/FCTX-Dandelion-Play/)
- **ローカル:** `index.html` をブラウザで開くだけです。ビルドもローカルサーバーも要りません。ただし Tailwind CSS とフォントを読み込むため、インターネット接続が必要です。

音が出ます。最近のブラウザなら、PCでもスマホでも動きます。

| ボタン | PC | スマホ |
|:--|:--|:--|
| 🖐️ **つかむ** | 根元・花・葉っぱの上で押してドラッグ | 指1本でタッチしてドラッグ。ほかの指は無視する |
| 🚿 **じょうろ** | 株の上でマウスボタンを押している間、水が出る。株の近くに落ちた水がしみこむ | 同じ |
| ⛏️ **くさぬき** | 株の根元のまわりをドラッグ | 同じ |
| 🌱 **つぎの草** | ランダムな新しい株に替える | 同じ |
| 🔍 **土のなか** | 断面を見せる／かくす | 同じ |
| 📖 **ずかん** | 最近の30回分の記録 | 同じ |
| ❓ **コツ** | 上手に抜くための3つのコツ | 同じ |

**キーボード:** Tab キーでプレイ画面を選びます。1・2・3 で つかむ・じょうろ・くさぬき を選び、スペース（または Enter）を押している間だけ道具を使います。押したまま矢印キーで動かします（Shift を押しながらだと細かく動く）。つかむでは左右に揺らしてから上へ引っぱります。N でつぎの草、Esc で開いているダイアログを閉じます。

根元（クラウン）は、地面の高さにある点線の円の中の小さな円盤です。「土のなか」を見せているときは、ミミズをタップするとクネクネ動き、ダンゴムシをタップすると丸くなります。

## 仕組み

すべて `index.html` 1ファイルに入っています。レイアウトは Tailwind CSS、プレイ領域は `<canvas>` 1枚、あとは素の JavaScript です。画像ファイルや音声ファイルは使っていません。

```
毎フレーム (requestAnimationFrame)
  |
  +- 物理        1/60 秒の固定ステップで、前のフレームからの経過時間ぶん進める
  |    +- 入力        このステップでのポインタの速さ、つかんでいる部位（根元・茎・葉）と引っぱった距離
  |    +- 土          抵抗 = max(0.15, 1 - (0.42 x 水分 + 0.45 x ほぐれ))
  |    +- 根のチェーン 根元から下へバネでつないだノード、側根の離脱、ノードごとの張力、破断か引き抜きか
  |    +- 周辺        水滴、白い汁、土ぼこり、綿毛、雲、ミミズとダンゴムシ
  +- 描画        画面の画素密度に合わせた Canvas 2D: 空、土の断面、根、葉、花、重ね描き
```

物理は固定ステップで進むので、60Hz でも 120Hz や 144Hz のディスプレイでも同じ速さで遊べます。

ヘッダー、プレイ領域、ボタンバーは別々の行に分けてあるので、株の上に文字やボタンが重なることはありません。品種名と記録はヘッダーの1行目にまとめて折り返さないようにしてあるので、数字が増えてもヘッダーの高さは変わりません。地面はプレイ領域の高さの48%の位置にあり、株はその上下に収まるように拡大縮小されます。スマホを横に倒したり、アドレスバーが引っ込んだりしてプレイ領域のサイズが変わったときは、株を替えずに、いまの株を新しいサイズに合わせて拡大縮小します。

### 主根はバネのチェーン

主根は根元から下へ並んだ11〜16個のノードです。各ノードは親ノードとの自然長、先端へ向かって細くなる半径、`28 + 4.6 × 半径` の強さを持っています。土は各ノードを元の位置へ引き戻そうとします。その力は中ほどの深さで最も強く、品種の「土のつかみ」、土の抵抗、そのノードのまわりのほぐれ具合、まだ付いている側根の数（1本ごとに32%増し）で決まります。

根元が上へ動くと、各ノードは親ノードについていきます。土に強くつかまれているノードほど動きにくいので、その間のバネが伸びます。この伸びが張力になります。

```
張力 = 伸び x (1 + 1.08 x 土の引き留め) x 角度ペナルティ x 速度ペナルティ
```

- **角度ペナルティ:** 親ノードが地上に出たあと、横へ引くと張力が最大2.6倍になる。
- **速度ペナルティ:** 物理の1ステップ（1/60秒）でポインタを14pxより多く動かすと、超えた1pxごとに5.5%増える。速さはステップごとに測り直すので、指を止めればすぐ0に戻る。

どこかのノードで張力が1.0に達すると、根はそこで切れ、それより下は土に残ります。付いているノードがすべて地上に出たら、根は先端まで抜けたことになります。地上に出たノードは土から自由になりますが、地面より10px以上深く押し戻されると、また土につかまれます。

### 側根と揺さぶり

側根は1本ずつ土に固定されています。ノードが固定点から `長さ + 12 × 土の抵抗 + 5` より遠くへ動くと、「プチッ」と外れます。根元を左右に揺らすと2つのことが起きます。土全体がほぐれ、さらにノード同士の横のずれで各ノードのまわりの土もほぐれます。だから引き上げる前に側根が外れていきます。

### 茎と葉

花や葉っぱは、つかんだだけではちぎれません。68px（葉は65px）より遠くへ引っぱったときだけちぎれます。それまでは指のほうへしなり、離すとビヨーンと戻ります。根元は、つかんだ瞬間の位置から少し引っぱられるだけなので、根元が地上に出たあとに花をつかんでも、土の中へ押し戻されることはありません。ちぎれた茎は中が空洞の切り株を残し、切り口から白い汁が出ます。

### 再生

根が切れたときは、結果のカードの **🌱 残った根から再生させる** で、土に残った根から同じ品種がまた生えてきます。約2.5秒かけて、根元から葉と花が伸び、根の上のほうが切れた位置まで太っていきます。土に残っていた部分は最初からあります。育ちきるまでは株をつかめません。

### 結果と保存

抜けた長さ（cm）は、地上に出た根のピクセル長 × 0.12 です。根のいちばん上の節で切れたときは、何も抜けていないので 0cm です。先端まで抜けたときは、25cm以上で **SSS**、18cm以上で **S**、それ未満で **A**。途中で切れたときは、根の長さの60%より多く抜けていれば **B**、そうでなければ **C** です。

抜いた数、最高記録、最近の30回分の記録は `localStorage`（キー `dandelion_sim_save_v2`）に保存されます。抜いた数は先端まで抜けたときだけ数えます。最高記録は途中で切れたときの長さも対象です。

保存データは読み込むときに中身を確かめます。足りない項目や壊れた項目は空の記録に置き換えるので、保存データがおかしくてもゲームは止まりません。記録は保存済みの内容を読み直してから追加するので、2つのタブで同時に遊んでも両方の記録が残り、もう一方のタブのヘッダーも合わせて更新されます。

### 音

Web Audio でその場で合成している音は8種類です。張力のきしみ（張力が上がるほど速く高くなる）、ブチッとちぎれる音、側根のプチッ、綿毛のフワッ、じょうろの水音、くさぬきのザクッ、先端まで抜けたときのスポッとハ長調のアルペジオ、そして再生するときのやさしい上昇音。ブラウザはユーザー操作のあとでないと音を出せないので、最初にタッチ・クリック・キー操作をしたときから鳴り始めます。着信などでブラウザやスマホが音を止めたときは、次にタッチしたときに再開します。Web Audio が使えないブラウザでは、音なしで動きます。

## アクセシビリティ

- **拡大できる。** ピンチ操作でページを拡大できます。タッチを横取りするのはプレイ領域だけで、そこでドラッグしてもページはスクロールしません。
- **キーボードで遊べる。** キーは[遊び方](#遊び方)にあります。プレイ領域には、スクリーンリーダー向けの名前とキーの説明を付けてあります。
- **ダイアログがダイアログとして動く。** 結果のカード、図鑑、コツは、開くとフォーカスが中へ移り、Tab で外へ出ず、Esc か外側のタップで閉じ、閉じるとフォーカスが元の場所に戻ります。
- **状態が読み上げられる。** アドバイスの帯はライブリージョンで、道具のボタンと「土のなか」の切り替えは、オンかオフかを伝えます。

## 検証

ヘッドレス Chromium と Playwright で確認しました。

- **35項目の自動チェック** で、このバージョンの修正をページそのものに対して確かめた。指を止めたときと1ステップあたりのポインタの速さ、壊れた保存データ（`null`、`[]`、一部だけのデータ、名前に HTML、JSON でない文字列）、幅 340px のスマホでのヘッダーの高さ、株を替えないリサイズ、画素密度、株を替えたあとの結果カード、再生、中断されたタッチと2本目の指、右クリック、0cm と B/C の判定、根の埋め戻し、株から離れた水やり、隠れた生き物、待機中のヘッダーの DOM 書き換え、ダイアログ、キーボード操作、ピンチ拡大、2つのタブ、物理が1秒60ステップで進むこと。34項目が通った。2本目の指のチェックは、テストの仕組みのせいで失敗した。DevTools プロトコルでは、2本の指のうち1本だけを離せないため。この場合は指ごとのポインタイベントを別々に送って確かめ直し、通った。
- **900 × 760 で実際にマウス操作:** セイヨウタンポポに水をやり、土をほぐし、揺らしながら引いて先端まで抜いた（23.2cm、ランクS）。花を引っぱって茎をちぎった。乾いた土からヌシの大タンポポを真上に急いで引き、根元のすぐ下で切れた（1.9cm、ランクC）。
- **390 × 844 のスマホエミュレーションでタッチ操作:** ヌシの大タンポポを途中で切り、再生させてから、水をやり、土をほぐし、揺らしながら引いて先端まで抜いた（33.1cm、ランクSSS）。そのあと図鑑を開いた。
- コンソールにエラーは出なかった。

テストした環境からは Tailwind の CDN につながらなかったので、代わりに Tailwind v4 のブラウザ版を読み込みました。公開しているページは v3 の Play CDN を使っているので、余白や影がスクリーンショットと少し違うかもしれません。この README のスクリーンショットはこの実行から撮ったもので、フォントは本物を使っています。操作に使ったスクリプトはこのリポジトリに含まれておらず、自動テストもありません。タッチ操作はエミュレーションだけで確かめていて、実機のスマホではまだ試していません。

## 既知の限界

- **日本語のみ。** 画面の文字はすべて日本語です。
- **ネット接続が必要。** 見た目は CDN から読み込む Tailwind のランタイムに頼っています。CDN が使えないと、スタイルがすべて外れ、結果のダイアログがボタンの下に出たままになります。
- **長さは画面に左右される。** 根はプレイ領域の高さに合わせて伸び縮みするので、端末が違うと記録を比べられません。引いている途中でプレイ領域のサイズが変わると、根もいっしょに拡大縮小され、新しいサイズで測られます。
- **操作は1つずつ。** 最初に触れた指、マウス、キーボードのどれか1つだけを追い、それが離れるまでほかの指は無視します。
- **幅の狭いスマホでは窮屈。** 幅 390px 以下だと、ゲージのラベルが2行に折り返します。
- **絵は説明されない。** スクリーンリーダーで読めるのはアドバイスの帯、ゲージ、ボタンで、キャンバスに描かれた絵の中身は伝わりません。
- **遅い端末ではゆっくりになる。** 1フレームに0.25秒より長くかかると、先へ飛ばさずにゲームの進みが遅くなります。
